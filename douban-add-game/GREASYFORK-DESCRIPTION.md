## 功能说明

在 Steam 商店页一键查豆瓣是否已收录这款游戏；若没有，一键跳转豆瓣「创建游戏条目」流程、**自动回填全部可填字段并注入封面**。全程人工只需核对 + 点提交，**绝不自动提交任何表单**。

适合在 Steam 上看到一款豆瓣还没收录的游戏时，几乎不用手动输入就把它加进豆瓣。

## 使用流程

1. 打开任意 Steam 商店页（`store.steampowered.com/app/…`），标题下方出现一条角标：
   - **已收录** → 条目链接 + 豆瓣评分，流程结束。
   - **名字相近** → 列出名字接近的条目让你先排除，确认都不是再添加。
   - **没搜到** → 「+ 添加到豆瓣」按钮。
   - **查重失败**（风控/网络）→ 降级为手动搜索链接，**绝不假装「没有」**。

   角标默认只占一行、配色取自 Steam 自己的面板，不抢版面；点「详情」才展开抓到的字段和告警。

2. 点「添加到豆瓣」→ 新标签打开豆瓣建条目流程，名称已带上。

3. **第一步**是豆瓣自己的查重，你确认列出的都不是同一款，点「以上都不是，继续创建」。脚本不会替你点这一步。

4. **第二步「详细资料」**：自动回填 **名称 / 中文名称 / 平台 / 类型 / 发售时间 / 简介**，并把 Steam 的竖版封面注入图标框。顶部横幅列出已填字段与需要注意的地方，你核对后点「好了，提交申请」。

你要做的就几下点击：Steam 上点「添加」，豆瓣第一步点一次「继续创建」，第二步核对后点一次「提交申请」。

## 特性

- **不刮 Steam 页面**，全部走官方 appdetails 接口取数据。页面改版不受影响，成人内容年龄门也不需要特殊处理。
- **中英文都要**：中文名与中文简介取自 Steam 简体中文商店页，发售日期取自英文页（中文页返回的是「2020 年 9 月 17 日」这种没法直接用的格式）。
- **中文名拿不到就留空**，不臆造翻译——Steam 上没有中文商店名的游戏，「中文名称」留给你填，并在角标上提示。
- **类型按 Steam 的分类 id 映射**到豆瓣类型，不按文案（文案会随语言变）。豆瓣没有对应的类型（独立、休闲、免费开玩等）不硬凑，列出来让你手动补。
- **不谎报**：每个字段回填后都从页面读回来核对，没真正填上的会明确列出来，不会让你以为填好了其实是空的。
- **绝不自动提交**：每一步都由你确认。
- 跨标签数据只存在本地，10 分钟过期、用完即删。

## 权限与隐私

- `@match` 仅 `store.steampowered.com/app/*` 与 `www.douban.com/game/create*`。
- `@connect store.steampowered.com`：读 Steam 官方 appdetails 接口。
- `@connect www.douban.com`：搜索这款游戏是否已收录。**仅读取公开信息，不做任何写操作。**
- `@connect shared.akamai.steamstatic.com`：抓取封面图。
- **不接入任何第三方或分析服务，不上传你的任何数据。**

## 注意

- **只处理游戏本体**：DLC、原声带、Demo 页面会静默跳过（豆瓣规范里 DLC / 资料片也应作为单独条目，需要的话请手动创建）。
- **成人内容游戏**首次打开会跳到 Steam 的年龄确认页，那一页不显示角标；过完年龄门回到商店页就正常了。
- **开发商 / 发行商 / 官方网站**：豆瓣建条目页没有这几个字段，脚本会把抓到的值列在横幅上，条目创建成功后请到条目编辑页补。
- **主机平台**：Steam 只能确知 PC / Mac / Linux，PS、Switch、Xbox 等需要你手动勾。
- 豆瓣搜索有频率限制，连续快速浏览很多游戏页可能触发风控；这时角标会显示「查重失败」并给出手动搜索链接。
