# userscripts

Browser userscripts for Tampermonkey / Violentmonkey.

## Scripts

| Script | Description | Install | Greasy Fork |
|--------|-------------|---------|-------------|
| [豆瓣条目 NeoDB 评分增强](douban-neodb-ratings/) | 在豆瓣条目页（书籍、电影、音乐、游戏）上添加 NeoDB.social 的评分展示（含条目链接） | [Install](https://raw.githubusercontent.com/lzblack/userscripts/main/douban-neodb-ratings/douban-neodb-ratings.user.js) | [Greasy Fork](https://greasyfork.org/zh-CN/scripts/559133-%E8%B1%86%E7%93%A3%E6%9D%A1%E7%9B%AE-neodb-%E8%AF%84%E5%88%86%E5%A2%9E%E5%BC%BA) |
| [豆瓣书名号转搜索链接](douban-title-mark-search/) | 将豆瓣网站上的书名号《》中的内容转换为可点击的搜索链接，就像豆瓣 App 一样！点击书名号内的文字即可快速搜索，无需手动复制粘贴。 | [Install](https://raw.githubusercontent.com/lzblack/userscripts/main/douban-title-mark-search/douban-title-mark-search.user.js) | [Greasy Fork](https://greasyfork.org/zh-CN/scripts/558844-%E8%B1%86%E7%93%A3%E4%B9%A6%E5%90%8D%E5%8F%B7%E8%BD%AC%E6%90%9C%E7%B4%A2%E9%93%BE%E6%8E%A5) |
| [豆瓣读书版本标记提示](douban-book-version-marker/) | 在豆瓣读书条目页提示你标记过同一作品的其他版本 | [Install](https://raw.githubusercontent.com/lzblack/userscripts/main/douban-book-version-marker/douban-book-version-marker.user.js) | [Greasy Fork](https://greasyfork.org/) |
| [X.com Draggable Tweets](x-draggable-tweets/) | Make entire tweet cards draggable as real links (works with Glitter Drag) | [Install](https://raw.githubusercontent.com/lzblack/userscripts/main/x-draggable-tweets/x-draggable-tweets.user.js) | [Greasy Fork](https://greasyfork.org/) |
