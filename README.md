# userscripts

Browser userscripts for Tampermonkey / Violentmonkey.

## Scripts

| Script | Description | Install | Greasy Fork |
|--------|-------------|---------|-------------|
| [豆瓣条目 NeoDB 评分增强](douban-neodb-ratings/) | 在豆瓣条目页（书籍、电影、音乐、游戏）上添加 NeoDB.social 的评分展示（含条目链接） | [Install](https://raw.githubusercontent.com/lzblack/userscripts/main/douban-neodb-ratings/douban-neodb-ratings.user.js) | [Greasy Fork](https://greasyfork.org/) |
| [豆瓣书名号转搜索链接](douban-title-mark-search/) | 将豆瓣网站上的书名号《》中的内容转换为可点击的搜索链接，就像豆瓣 App 一样！点击书名号内的文字即可快速搜索，无需手动复制粘贴。 | [Install](https://raw.githubusercontent.com/lzblack/userscripts/main/douban-title-mark-search/douban-title-mark-search.user.js) | [Greasy Fork](https://greasyfork.org/) |
| [X.com Draggable Tweets](x-draggable-tweets/) | Make entire tweet cards draggable as real links (works with Glitter Drag) | [Install](https://raw.githubusercontent.com/lzblack/userscripts/main/x-draggable-tweets/x-draggable-tweets.user.js) | [Greasy Fork](https://greasyfork.org/) |
