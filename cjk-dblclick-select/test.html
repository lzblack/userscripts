CJK Double-Click 测试

在每个用例上双击，应得到 预期 的选择。

1. 纯中文，无标点

今天天气很好我们一起去公园吧

预期：双击任意字 → 全选这段
2. 半角分隔的句子

今天天气很好，我们一起去公园吧。

预期：双击 好 → 今天天气很好；双击 园 → 我们一起去公园吧
3. 中英混排

Today 今天 is 晴天 weather

预期：双击 今 → 今天；双击 quick 之类英文 → 单词级（脚本不干预）
4. 数字夹中文

价格是 100 元整

预期：双击 元 → 元整；双击 100 → 数字（脚本不干预）
5. 纯英文，不应触发

The quick brown fox jumps over the lazy dog

预期：双击 → 单词级原生行为
6. input：原生行为

预期：双击 input 内任意字 → 浏览器原生选择（脚本不干预）
7. 跨 span

今天天气很好

预期：双击任意字 → 今天天气很好（跨三个 span 合并）
8. 嵌套 block 应阻断
今天
新段落
剩余
预期：双击 余 → 剩余（不应吸进"新段落"）
9. contenteditable

今天天气很好，可编辑区域也要工作。

预期：双击 好 → 今天天气很好
10. 标点夹在中间

第一段·第二段

预期：双击 第（任一）→ 只选所在的"第一段"或"第二段"（· 是非汉字，作边界）
11. 日文：汉字 + 假名混排

今日はいい天気ですね

预期：双击任意字（含假名 は / ですね）→ 全选这段（假名不再断句）
12. 日文：半角句点分隔

東京に行きました。映画を見ました。

预期：双击前句任意字 → 東京に行きました；双击后句 → 映画を見ました（。 作边界）
13. 韩文：空格即词边界

안녕하세요 반갑습니다

预期：双击 안녕하세요 内任意字 → 안녕하세요（停在空格，正好一个词）
14. <br> 换行即边界（裸文本节点 + br，仿 Vue 组件结构）
睡沙发的人

讲中国高考问题的，说实话，我挺震惊的

我以为都是短剧风
预期：双击 睡沙发的人 任意字 → 睡沙发的人（向右不越过 br）；双击 讲 → 讲中国高考问题的（向左不越过 br 吸回上一行）
