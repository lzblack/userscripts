## 功能说明

在豆瓣广播流（首页 + 成员 statuses 广播页）中，当好友分享了书影音游戏条目时，自动显示你自己对该条目的标记状态和评分。豆列页同样支持——刷别人的书单／片单时，标过的条目会直接盖上印章。

## 两种显示模式

通过 Tampermonkey 菜单「切换显示模式（印章 / 标签）」一键切换：

**印章模式**（默认）——仿豆瓣 app 盖章效果，圆形橙褐色印章显示在卡片右下角：
- 已读过 / 已看过 / 已听过 / 已玩过 → 印章 + 星级
- 已想读 / 已在看 等 → 印章 + ✓

**标签模式**——简洁 inline 标签显示在标题行末尾：
- `已读过 ★★★★`、`已想看`、`已在听 ★★★`

未标记过的条目不显示任何内容，不干扰阅读。

支持所有类型的广播——标记动态、短评、长评、收藏到片单、转发等，只要广播中出现了条目链接就会检测。豆列页则逐条读取条目卡片，分类豆列和通用豆列都能识别类别。

## 支持的条目类型

| 类型 | 标记状态 |
|------|----------|
| 书籍 | 已想读 / 已在读 / 已读过 |
| 影视 | 已想看 / 已在看 / 已看过 |
| 音乐 | 已想听 / 已在听 / 已听过 |
| 游戏 | 已想玩 / 已在玩 / 已玩过 |

## 特性

- 自动扫描当前页面所有条目链接，去重后批量查询；下拉加载的新广播也会自动检测
- 带缓存：已标记条目缓存 7 天，未标记条目缓存 1 天，避免重复请求
- 并发控制：最多同时 3 个请求，不会触发豆瓣限流
- 需要登录豆瓣才能检测标记状态，未登录时不显示任何内容

## 权限与隐私

- 仅匹配 `https://www.douban.com/` 首页、`https://www.douban.com/people/*/statuses` 广播页和 `https://www.douban.com/doulist/*` 豆列页，不会在其它页面注入
- 通过豆瓣内部接口读取你自己的标记状态，不会执行任何写操作
- 缓存数据存储在本地（Tampermonkey 存储），不会发送到任何外部服务
