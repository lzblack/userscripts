## 功能说明

在豆瓣首页广播流中，当好友分享了书影音游戏条目时，自动显示你自己对该条目的标记状态和评分。

**效果示例：**

- 标题行末尾出现绿色标签：`已看 ★★★★`、`想读`、`在听 ★★★`
- 未标记过的条目不显示任何内容，不干扰阅读

支持所有类型的广播——标记动态、短评、长评、收藏到片单、转发等，只要广播中出现了条目链接就会检测。

## 支持的条目类型

| 类型 | 标记状态 |
|------|----------|
| 书籍 | 想读 / 在读 / 已读 |
| 影视 | 想看 / 在看 / 已看 |
| 音乐 | 想听 / 在听 / 已听 |
| 游戏 | 想玩 / 在玩 / 已玩 |

## 特性

- 自动扫描当前页面所有条目链接，去重后批量查询
- 带缓存：已标记条目缓存 7 天，未标记条目缓存 1 天，避免重复请求
- 并发控制：最多同时 3 个请求，不会触发豆瓣限流
- 需要登录豆瓣才能检测标记状态，未登录时不显示任何内容

## 权限与隐私

- 仅匹配 `https://www.douban.com/` 首页，不会在其它页面注入
- 通过豆瓣内部接口读取你自己的标记状态，不会执行任何写操作
- 缓存数据存储在本地（Tampermonkey 存储），不会发送到任何外部服务
