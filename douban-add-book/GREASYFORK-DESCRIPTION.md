## 功能说明

在 Amazon 图书页一键查豆瓣是否已收录；若未收录，一键跳转豆瓣「添加书籍」流程、**自动回填全部可填字段并注入封面**。全程人工只需审核 + 点提交，**绝不自动提交任何表单**。

适合在 Amazon 看到一本豆瓣还没有的英文原版书时，几乎不用手动输入就把它加进豆瓣。

## 使用流程

1. 打开任意 Amazon 图书页（`www.amazon.com/…/dp/…`），页面标题下方出现角标：
   - **已收录** → 显示豆瓣评分 + 直达条目链接，流程结束。
   - **有其他版本** → 显示「豆瓣有其他版本」+ 链接，并提供「仍要添加此版本」。
   - **未收录** → 显示「+ 添加到豆瓣」按钮。
   - **查重失败**（风控/网络）→ 降级为手动搜索链接，绝不假装「未收录」。

   角标同时列出脚本提取到的字段（标题/副标题/作者/出版社/日期/页数/装帧/定价/简介），点添加前一目了然。

2. 点「添加到豆瓣」→ 新标签打开豆瓣添加页，脚本自动填好 ISBN，你点「下一步」（豆瓣在此做服务端查重，是第二道保险）。

3. 第二步表单：自动回填 **书名 / 副标题 / 作者（多作者自动加行）/ 定价 / 出版社 / 出版日期 / 装帧 / 页数 / 内容简介 / 作者简介**，顶部摘要条列出「已填 / 跳过 / 警告」。你核对后点「下一步」。

4. 上传封面页：自动把 Amazon 高清封面注入文件框，你点「上传图片」即可。

你要做的就几下点击：Amazon 上点「添加」，豆瓣两步表单各点一次「下一步」，封面页点一次「上传图片」。其余字段全部自动填好，你只负责核对。

## 特性

- **查重 + 取分一步到位**：走 `book.douban.com/isbn/{isbn}/`，命中直接解析评分。
- **兼容 Amazon 新版布局**：支持现行的 Rich Product Information 卡片，也兼容旧版 detail-bullets / 表格。
- **内容简介干净**：按结构提取，剥除「Read more」展开按钮、不重复不错序。
- **多作者自动加行**：人物实体关联栏按豆瓣规范留空、人工处理。
- **绝不自动提交**：每一步都由你确认，错了随时改。
- **跨标签数据本地传递**：10 分钟过期、消费即删，不污染下一本。

## 权限与隐私

- `@match` 仅 `www.amazon.com` 与 `book.douban.com/new_subject`；Amazon 上的非图书页静默退出，不干扰。
- `@connect book.douban.com`：用你的豆瓣登录态查询某 ISBN 是否已收录（登录态也是绕开风控的必要条件）。**仅读取公开收录信息，不做任何写操作。**
- `@connect media-amazon.com / ssl-images-amazon.com`：抓取封面图。
- **不接入任何第三方或分析服务，不上传你的任何数据**；跨标签传递的数据只存在本地 Tampermonkey 存储，用完即删。

## 注意

- **不支持 Kindle / 电子版**：Kindle 页没有 ISBN（豆瓣也不收录电子书），脚本会提示你切到纸质版（print edition）页面再用。
- 主要面向英文原版书（美国 Amazon）。
- 副标题来自 Amazon 标题按冒号拆分，偶有营销语混入；摘要条会展示供你复核，也可在豆瓣页手改。
- 极新 / 独立出版（KDP）书 Amazon 数据可能不全，按摘要条提示人工补。
